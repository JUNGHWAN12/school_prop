[요구사항 명세서] 견적서 기반 K-에듀파인 연동 자동 품의문·품목내역 엑셀 생성 시스템
1. 프로젝트 개요
프로젝트명: AI 기반 견적서 분석 및 K-에듀파인 맞춤형 품의문·품목내역 엑셀 생성기 (가칭: Edu-Approval)
목적:
교직원이 첨부한 견적서(PDF/이미지)를 Gemini API로 해독하여 K-에듀파인 품목내역 엑셀 파일(`.xls` / `.xlsx`)을 서식 손상 없이 자동 생성.
상황별(약식 물품구매, 대회/행사 참가, 식비/급량비 등) 표준 공문 양식에 맞춘 다양한 품의 템플릿 선택 및 자동 채우기 지원.
주요 타깃 사용자: 유·초·중·고교 및 직속기관 교원, 학교 행정실 지출·회계·물품 담당자.
---
2. 기술 스택 및 아키텍처 정의
Frontend: React.js 또는 Vue.js 3 (단일 SPA 프레임워크 선정 적용)
UI/UX: Tailwind CSS, Lucide Icons
상태 관리: Pinia (Vue) 또는 Zustand / Redux Toolkit (React)
AI Model: Google Gemini API (`gemini-1.5-flash` / `gemini-1.5-pro` 멀티모달 Vision)
Excel 엔진: `exceljs` 또는 `xlsx` (SheetJS)
첨부 서식인 K-에듀파인 `품목내역(통합).xls` 헤더 구조 및 열 규격 100% 매핑

3. 핵심 시스템 기능 요구사항 (Functional Requirements)
3.1 견적서 파일 업로드 및 데이터 추출 (FR-01)
지원 포맷: PDF, JPG, PNG (단일/복수 페이지 지원, 최대 20MB)
AI 데이터 파싱 (Gemini API):
공급자 정보: 상호명, 등록번호, 견적일자
품목 리스트: 품명, 규격, 단위, 수량, 단가, 공급가액, 세액, 총금액
대표 품목 요약: "첫 번째 품목명 외 N건" 규칙 자동 계산
---
3.2 다중 품의 템플릿 선택 및 지능형 본문 렌더링 (FR-02) ★
사용자가 품의 목적에 맞춰 템플릿을 선택하거나 AI가 견적서 성격을 분석하여 자동 추천합니다.
[템플릿 유형 1] 일반 물품/도서 구매형 (약식)
특징: 단순 도서, 학습준비물, 소모품 등 긴 개요가 필요 없는 일상적 구매.
출력 형식:
```text
  [사업/목적명]을 위한 [품목 구분]를 다음과 같이 구입하겠습니다.
    1. 품목: {대표품목명} 외 {N}건
    2. 금액: 금 {총금액}원 (금 {한글금액}).  끝.
  ```
[템플릿 유형 2] 행사·대회 참가 및 연수형
특징: 관련 공문 번호, 주최/주관, 기간, 참가 인원 및 산출식(단가 × 인원) 명시.
출력 형식:
```text
  1. 관련: {부서/기관명}-{문서번호}({시행일자}) 「{관련문서제목}」
  
  2. 행사 개요
    가. 행사명: {행사명}
    나. 주최/주관: {주최기관}
    다. 참가 기간:
      1) [{세부일정1}] {일시/기간}
      2) [{세부일정2}] {일시/기간}
    라. 참가 인원: {대상} 총 {인원}명
  
  3. 소요 예산 내역
    가. 총 소요액: 금{총금액}원 (금{한글금액})
    나. 산출 내역: {1인당금액}원 × {인원}명 = {총금액}원
  
  붙임  {행사명} 참가학생 명단 1부.  끝.
  ```
[템플릿 유형 3] 식비 / 급량비 / 다과비 지출형
특징: 행사 일시, 식비 지출 시간대, 참가 대상 명단 및 1인당 식비 산출식 포함.
출력 형식:
```text
  1. 관련: {관련문서번호 및 제목} (선택 사항)
  
  2. {행사/사업명}에 따른 학생(교직원) 점심(저녁) 식비를 지출하겠습니다.
    가. {행사명} 일시: {행사일시}
    나. 식비지출일정: {식사제공일시}
    다. 대상: {대상 설명} {인원}명
    라. 소요예산액: 금{총금액}원 (금{한글금액})
  
  붙임  {행사명} 참가학생 명단.  끝.
  ```
템플릿 공통 편집 기능:
AI 추출값 자동 바인딩 (금액의 한글 표기 `금 팔만오천칠백칠십원` 자동 환산)
공문 번호, 행사 일시, 참가자 수 등 미추출 항목에 대한 인라인 폼 입력
[품의문 본문 클립보드 복사] 버튼 제공 (K-에듀파인 품의 본문창에 바로 붙여넣기 지원)

3.3 K-에듀파인 표준 '품목내역(통합)' 엑셀 파일 생성 (FR-03) ★
사용자가 첨부한 `품목내역(통합) (6).xls` 원본 서식의 규격을 엄격히 준수하여 엑셀을 생성합니다.
엑셀 시트 명세 (단일 Sheet: `품목내역`, 원본 서식 기준 5열)
컬럼 순서	컬럼명 (헤더 1행)	데이터 타입	필수 여부	매핑 및 변환 규칙
A	내용	문자열	필수	품목명 기재 (예: 공간이 만든 공간)
B	규격	문자열	선택	모델명, 저자, 크기 등 (없을 경우 공란 또는 `-`)
C	단위	문자열	필수	개, 권, 명, 식, 회 등 (기본값: '개' 또는 '권')
D	수량	숫자 (Integer)	필수	콤마 없는 순수 정수/소수 숫자
E	예상단가	숫자 (Integer)	필수	부가세(VAT) 포함 최종 단가 (예상금액 열은 서식에 없음)
엑셀 생성 검증 규칙
헤더 고정: 1행 헤더 레이블(`내용`, `규격`, `단위`, `수량`, `예상단가`) 절대 변경 금지. (원본: docs/samples/품목내역(통합)_원본서식.xls)
셀 병합(Merge) 금지: K-에듀파인 엑셀 일괄등록 파서 파손 방지.
숫자 필드 무결성: D, E열은 텍스트 포맷이 아닌 반드시 Excel Number Type으로 저장.
다운로드 파일명 규격: `품목내역(통합)_{대표품목명}_{작성일자}.xlsx` (기본, 보조로 `.xls` 제공)

5. 데이터 처리 파이프라인
Upload & Preprocessing: 견적서 업로드 ➔ 이미지/PDF 바이너리 준비.
Gemini 1.5 Vision Request:
시스템 프롬프트: 품명, 규격, 단위, 수량, 공급단가, 세액, 총액 추출 및 품의 유형(도서/대회/식비 등) 자동 추천.
Structured JSON Output:
```json
   {
     "suggested_template": "TEMPLATE_EVENT",
     "vendor_name": "(사)한국비버정보교육연합",
     "total_amount": 24000,
     "total_amount_korean": "금이만사천원",
     "items": [
       {
         "item_name": "비버챌린지 2026 참가비",
         "spec": "초·중·고 학생",
         "unit": "명",
         "quantity": 8,
         "unit_price": 3000,
         "amount": 24000
       }
     ]
   }
   ```
Draft Generation:
선택된 템플릿(약식, 행사, 식비)에 JSON 데이터를 바인딩하여 품의문 본문 완성.
Excel Export:
K-에듀파인 업로드 규격에 맞춰 `내용`, `규격`, `단위`, `수량`, `예상단가` 열을 정렬하여 `.xls` 바이너리 생성.

6. 개발·실행 방법

구조: `web/`(React + Vite + TS), `server/`(Hono, Cloudflare Workers 배포 가능), `docs/samples/`(K-에듀파인 원본 서식). 상세 계획은 `개발계획서.md`.

```powershell
# 서버 (http://localhost:8787) - Windows PowerShell, 한 줄씩 실행
cd server
npm i
copy .env.example .env
notepad .env          # UPSTAGE_API_KEY, GEMINI_API_KEY 입력 후 저장
npm run dev

# 웹 (http://localhost:5173, /api 는 8787로 프록시) - 새 PowerShell 창에서
cd web
npm i
npm run dev

# 테스트
cd web
npm test
cd ..\server
npm test
```
- API 키는 서버 환경변수로만 관리하며 클라이언트에 노출되지 않습니다. `.env`는 커밋 금지.
- 배포: 웹은 GitHub Pages, API는 Cloudflare Workers. 절차는 `docs/배포가이드.md` 참고(`.github/workflows/pages.yml`, `worker.yml`).
- Upstage 엔드포인트·모델명(`UPSTAGE_PARSE_MODEL`, `UPSTAGE_SOLAR_MODEL`)과 Gemini 모델명(`GEMINI_MODEL`)은 환경변수로 교체 가능합니다. 실제 키로 호출 검증 전이므로 공식 문서와 대조가 필요합니다.
