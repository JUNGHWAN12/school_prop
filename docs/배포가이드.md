# 배포 가이드 (GitHub Pages + Cloudflare Workers, 무료)

구성: **웹(React 정적 파일) → GitHub Pages**, **API(Hono) → Cloudflare Workers**. API 키는 Workers 시크릿에만 저장합니다.

## 0. 준비 (Windows PowerShell 기준)
- Node.js 22 LTS 설치(https://nodejs.org), Git 설치 후 **새 PowerShell 창**을 엽니다. 관리자 권한/`C:\WINDOWS\system32`는 쓰지 말고 일반 폴더에서 작업하세요.
- 구버전 PowerShell(5.x)은 `&&`를 지원하지 않으므로 **명령을 한 줄씩 실행**합니다.
```powershell
cd $HOME\Documents
git clone https://github.com/JUNGHWAN12/school_prop
cd school_prop
git checkout claude/wonderful-brown-hi5a97   # main에 병합 전이라면
```

## 1. API 배포 (Cloudflare Workers)
1. Cloudflare 가입(무료) 후 아래를 한 줄씩 실행 (브라우저가 열려 로그인/허용)
   ```powershell
   cd server
   npm i
   npx wrangler login
   ```
2. 시크릿 등록 (값은 프롬프트에 직접 입력, 채팅·커밋에 붙여넣지 말 것)
   ```bash
   npx wrangler secret put UPSTAGE_API_KEY
   npx wrangler secret put GEMINI_API_KEY
   ```
3. `server/wrangler.toml`의 `ALLOWED_ORIGIN`을 본인 GitHub Pages 출처로 수정 (예: `https://<계정>.github.io`, 경로 제외)
4. `npm run deploy` → 출력되는 주소(`https://edu-approval-api.<서브도메인>.workers.dev`)를 메모
5. 확인: `curl https://<워커주소>/api/health` → `{"ok":true}`

(선택) GitHub Actions로 배포: 저장소 Secrets에 `CLOUDFLARE_API_TOKEN`(Workers 편집 권한), `CLOUDFLARE_ACCOUNT_ID` 등록 후 Actions 탭에서 "Deploy API to Cloudflare Workers" 수동 실행.

## 2. 웹 배포 (GitHub Pages)
1. 저장소 **Settings → Pages → Source: GitHub Actions** 선택
2. **Settings → Secrets and variables → Actions → Variables**에 `API_BASE_URL` = 위 4번의 워커 주소(끝에 `/` 없이)
3. `main`에 `web/**` 변경이 푸시되면 자동 배포됩니다. (수동: Actions → "Deploy web to GitHub Pages" → Run)
4. 주소: `https://<계정>.github.io/<저장소명>/`

## 3. 운영 점검
- 접속 제한 없음(로그인 없는 공개 API): 남용은 IP당 분당 요청 수·일일 호출 상한으로만 제한됩니다. 이상 징후 시 `RATE_LIMIT_PER_MIN`·`DAILY_CALL_LIMIT`을 낮추거나, Cloudflare 대시보드의 Rate limiting/Turnstile 적용을 검토하세요.
- 비용 통제: Upstage/Google 콘솔에서 월 한도 설정, 결제수단 미등록. Workers 무료 한도(요청 수·CPU 시간)는 Cloudflare 대시보드에서 확인
- 실시간 로그: `npx wrangler tail` (견적서 본문·개인정보는 로그에 남기지 않음)
- 장애 시: AI 분석이 실패해도 품목 직접 입력으로 품의문·엑셀 생성 가능
